## Investigation Findings

### Data (Snowflake / Datadog / Mixpanel)
For each source:
- Every query run or generated, formatted for re-execution. Label as **[Run via MCP]** or **[Manual — run in {tool}]**.
- Summary of results, or "No results" / "Access unavailable".
- Interpretation: what does this tell us about the bug?

### Codebase

### Feature Flags (LaunchDarkly)

### Slack / Historical Context
For every relevant thread: **[#channel-name — brief description](actual-slack-url)** followed by 1-2 sentences on relevance.

### Reproduction Attempts

#### Human-Readable Reproduction Steps
Numbered steps for manual reproduction in dev. Derived from code analysis, confirmed or corrected by the Playwright run.

#### Automated Reproduction (Playwright)
What the agent did, what it observed, whether the bug was reproduced. Note any blockers.

#### Screen Recording
Path to the `.webm` or `.mp4` video, or note that it needs manual attachment.

## Recommended Fix
High-level description. No code changes — recommendation only.

## Open Questions
Anything unresolved or needing follow-up.

## Prevention
What could prevent this class of bug in the future?
